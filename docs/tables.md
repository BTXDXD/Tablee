# Таблицы

Таблицы - это основа Tablee. На них строится всё: переменные, функции, шаблоны и т.д. 

---

| Тип таблицы    | Идентификатор | Инициализация                                                                 | Назначение                                |
|----------------|---------------|-------------------------------------------------------------------------------|-------------------------------------------|
| Табулярная     | `tabular`     | `new` `Name` `{...}` `;`                                                      | Группировка таблиц                        |
| Функциональная | `functional`  | `new` `functional` `Name` `(...)` `{...}` `;`                                 | Определение функции с аргументами и телом |
| Переменная     | `variable`    | `new` `[template]` `name` `;` <br><br>`new` `[template]` `name` `=` `...` `;` | Хранение данных                           |

// дополнить тем, что может быть вместо ... - новый файл

| Подвид таблицы | Идентификатор | Применимо к | Назначение                                                     |
|----------------|---------------|-------------|----------------------------------------------------------------|
| Шаблонная      | `template`    | `tabular`   | Служит схемой для создания типов переменных и сложных структур |
| Расширяемая    | `extendable`  | `tabular`   | Разрешает создание и удаление подтаблиц                        |
| Константная    | `const`       | `variable`  | Запрещает изменение переменной после инициализации             |

В любую таблицу кроме переменной может быть вложена любая другая таблица.
