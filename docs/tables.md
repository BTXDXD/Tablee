# Таблицы

Таблицы - это основа Tablee. На них строится всё: переменные, функции, шаблоны и т.д. 

---

| Тип таблицы    | Идентификатор | Инициализация                                       | Назначение                                                     |
|----------------|---------------|-----------------------------------------------------|----------------------------------------------------------------|
| Табулярная     | `tabular`     | `new` `<extendable>` `Name` `{...}` `;`             | Группировка таблиц                                             |
| Шаблонная      | `template`    | `new` `<extendable>` `template` `Name` `{...}` `;`  | Служит схемой для создания типов переменных и сложных структур |
| Функциональная | `functional`  | `new` `Name` `(...)` `{...}` `;`                    | Определение функции с аргументами и телом                      |
| Переменная     | `variable`    | `new` `name` `;` <br><br>`new` `name` `=` `...` `;` | Хранение данных                                                |

// дополнить тем, что может быть вместо ... - новый файл
// [] помечает табулярную таблицу расширяемой (без extendable) - новый файл

| Подвид таблицы | Идентификатор | Применимо к           | Назначение                                                     |
|----------------|---------------|-----------------------|----------------------------------------------------------------|
| Расширяемая    | `extendable`  | `tabular`, `template` | Разрешает создание и удаление подтаблиц                        |
| Константная    | `const`       | `variable`            | Запрещает изменение переменной после инициализации             |

// если создаем расширяемую `tabular`, то нужно использовать [] в конце названия. В скобках можно указывать допустимые шаблоны. Если пусто - разрешены любые.

В любую таблицу кроме переменной может быть вложена любая другая таблица.
