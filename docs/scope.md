# Область видимости

Видимость элементов в Tablee определяется иерархией вложенности таблиц.

### Лексическая видимость
Любая таблица автоматически «видит» все подтаблицы своих родительских таблиц по цепочке снизу вверх вплоть до корня `Global`:
```
Global {
    Main {
        AnyTable {}; // «Видит» всё, что объявлено ранее
    };
};
```
### Изоляция
Элементы, объявленные внутри табулярных или функциональных таблиц, являются локальными. Таблицы снаружи не видят внутренние таблицы напрямую - обратиться к локальной подтаблице снаружи можно по ее полному пути через точки:
```
MainTabular.ChildTabular.variableName;
```

### Изоляция функций
Аргументы и таблицы, созданные внутри функциональных таблиц, существуют только во время их выполнения.
Локальные переменные автоматически удаляются из памяти после завершения работы функции.

### Глобальный уровень
Все таблицы первого уровня видны всей программе без необходимости указывать путь.
